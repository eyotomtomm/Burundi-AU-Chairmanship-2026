Home “New today” Rail

The swipeable cards at the very top of the home screen. Set how many of each content type appear — set a number to 0 to leave that type out. Cards show in the order listed below.

sensors Live feeds Streams that are on air right now
newspaper News & articles Newest published stories
event Events Next upcoming events
auto_stories Magazines Latest published editions
play_circle Videos Featured videos first
stars Discover cards Your Feature Cards

Changes reach the app within about a minute (home feed cache). If nothing is published for a type, the rail simply skips it.
